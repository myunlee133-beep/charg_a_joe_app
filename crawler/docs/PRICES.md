# 가격 파서 원칙

| 원문 | 결과 | 상태 |
|---|---:|---|
| `8,3000원` | **8,300원** | `trailing_zero_corrected` (호구세트) |
| `1,2300원` | 1,230원 | `trailing_zero_corrected` |
| `10,000원` | 10,000원 | `as_published`, 변경하지 않음 |
| `5.900원` | 5,900원 | `dot_thousands_normalized` |
| `8,3001원` | 결측 | `needs_review`, 임의 보정 불가 |
| `5,200원 / 7,700원` | 결측 | `multiple_prices`, 옵션 분리 필요 |

**보정 조건:** 쉼표로 나뉜 마지막 그룹이 천 단위(3자리)가 아니라 4~5자리이고, 초과한 끝 숫자가 **전부 `0`**인 경우에만 초과한 0을 제거합니다. 정당한 실제 가격(예: `10,000원`, `1,000원`, `100,000원`)은 절대 끝자리 0을 빼면 안 됩니다.

독립 크롤러는 `raw_text`, `price_raw`, `price_status`를 그대로 저장해 자동 보정 내역을 추적합니다. 이상치 규칙은 새로운 실제 사례가 확인되기 전까지 임의로 확대하지 않습니다.

고정 메뉴의 `호구세트`는 2026-10-22에 사용자가 확인한 **8,300원**으로 등록했습니다. 원문 페이지에는 `8,3000원`으로 표시됩니다.
