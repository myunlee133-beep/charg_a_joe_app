# 식샤 V2 seed vs 찾아줘 크롤러 식당 등록부

기준: [식샤 공개 마이그레이션 V8 SQL](https://github.com/wafflestudio/siksha-spring/blob/main/core/src/main/resources/db/migration/V8__split_v2_building_restaurant_custom.sql)에 초기 생성된 `restaurant_v2` **31개 코너/식당**. **현재 식샤 운영 서버 데이터 또는 앱의 실시간 목록이 아님.**

확인한 바 31개 중 일부는 기존 찾아줘 크롤러에서 `3식당`, `301동식당`, `220동식당` 같은 **상위 식당 한 행으로 합쳐** 다뤘습니다. 이제 31개 단위가 각기 별도의 정식 식당/코너명으로 등록되어 있습니다. 동명이인/코너명 표기가 바뀌는 경우 `restaurant_unit` 매핑과 테스트를 업데이트하세요.

## 공식 안내에서 추가한 2곳

- **버거운버거** (101동, 아시아연구소 1층): 공식 생협 식당안내/식단 모두 등재, 식샤 V2 seed에는 없음. 별도 고정 메뉴 116옵션.
- **프레퍼스** (113동, 동원생활관 1층): 공식 생협 식당안내에 등재, 식샤 V2 seed에는 없음. **메뉴 크롤링 출처 미확인**이므로 운영시간·위치만 등록하고 메뉴는 비워둠.

## 갱신/모호성

- 건물-식당 관계와 위치는 공식 식당안내를 우선합니다. 해당 안내의 홈페이지가 갱신되지 않았거나 일시 휴업한 경우 데이터는 현실과 차이가 날 수 있습니다.
- 식샤 초기 seed에는 버거운버거와 프레퍼스가 없지만 **식샤가 현재도 이 두 식당을 제공하지 않는다고 말할 수는 없습니다**.
- 301동·75-1동의 소단위가 공식 날짜별 페이지의 HTML에서 표기되지 않는 날에는 단위 식별이 불완전할 수 있습니다. 값이 없으면 상위 식당 원문으로 보존합니다.
- 카페, 편의점 등 **식당안내 이외의 카페안내 전체 목록은 이번 33개 비교 범위가 아닙니다**.
