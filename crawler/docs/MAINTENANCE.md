# 파서 유지보수 및 장애 대응

## 데이터 품질 기준

1. `menu_lines.csv`는 원문 줄을 유실하지 않는 것이 우선입니다. 실제 데이터 확인 전 가격 없는 줄을 단독 판매 메뉴로 확정하지 마세요.
2. `menu_items.csv`는 가격이 확인된 날짜별 항목과 고정 카탈로그 가격 옵션만 제공합니다. `<뷔페> 6,500원`처럼 대표 식사 가격이 명시된 경우 `뷔페`를 유료 판매 단위로도 남기고, 구성 반찬은 원문으로 보존합니다.
3. `(#)` 미표기는 `no_meat_label = null`입니다. 이를 고기가 있는 음식이라고 추정하지 않습니다.
4. 수의대의 가격 미표기 메뉴는 `menu_entries.csv`에는 포함되지만 `menu_items.csv`에는 포함되지 않습니다.
5. 건물 매핑이 불확실하거나 신규 식당이면 건물 번호가 `null`로 기록됩니다. 버거운버거=101동 아시아연구소 1층, 공대간이식당=30-2동을 확인했습니다.
6. 호출 실패와 파서 실패는 `errors.json`, 요약은 `manifest.json`으로 기록합니다. 저장 결과가 있더라도 부분 실패일 수 있습니다.

## 변경 대응

- **식단 테이블 없음**: HTML 변경이나 접근 차단 가능성. 자동으로 다른 페이지를 파싱하지 말고 실제 사이트 구조 확인.
- **요청 날짜 불일치**: 캐시/차단/서버 정책 변경 가능성. 날짜를 억지로 바꾸지 않음.
- **수의대 주간 날짜 이상**: 날짜 라벨에 연도가 없기 때문에 조회 시점에서 35일 이내의 달력상 맞는 연도만 채택.
- **HTTPS 오류**: 서버 담당자 문의. TLS 검증 해제 금지.
- **새로운 가격 표기**: 오판 방지를 위해 원문 유지, 명시적인 새 파싱 규칙과 테스트 추가.
- **고정 메뉴 변경**: `src/chajwo_meals/data/fixed_menu_catalog.csv`를 수정하고 `tests/test_fixed_menus.py` 실행. 기존 파일을 자동 덮어쓰지 않음.
- **가격 오류**: 공식 표기 `8,3000원`은 검증된 가격 **8,300원**으로 보정하고 `trailing_zero_corrected` 플래그를 남깁니다. 다른 불확실한 가격은 `needs_review`와 원문을 보존합니다.

## 실제 서비스 연동 계획

직접 만든 크롤러를 서버 프로세스로 실행할 수 있지만 외부 서비스에 의존하므로 네트워크 오류, 데이터 품질, 운영 조건을 먼저 확인해야 합니다. SQLite/PostgreSQL 적재는 `--write-db`로 지원합니다. 실제 서비스의 외부 API/인증은 찾아줘 측에서 별도로 정의해야 합니다.
