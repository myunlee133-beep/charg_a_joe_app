# iOS 편의시설 탐색 · 2026-11-27

Craft Read: 캠퍼스 학생을 위한 실용적인 지도·시설 상세. 기존 초록과 흰색, variance 4. 시설 종류 배지와 층별 세로 기준선으로 장소의 분류와 위치를 함께 전달한다.

범위는 기존 SwiftUI 지도·시트·탭의 개선이다. Android, AR, 셔틀·식단 로직은 바꾸지 않는다. 네이티브 SwiftUI이므로 웹 DOM/CSS용 ui-craft-detect 수치는 적용하지 않으며 XCUITest 캡처로 확인한다.

| 기존 | 수정 | 목적 |
| --- | --- | --- |
| 시설 이름으로 건물만 검색 | 시설·건물 결과를 구분하고 건물·층 표시 | 실제로 찾는 매장을 먼저 선택 |
| 건물 클릭 즉시 큰 시트 | 요약 → 건물 상세 또는 종류 배지 | 지도 맥락과 점진적 공개 |
| 모든 시설에 같은 건물 아이콘 | 기능별 SF Symbol과 작은 배지 | 종류를 짧게 구분 |
| 층 한 개씩 이름만 확인 | 전체 층 기준선 + 종류/층 필터 + 시설 상세 | 탐색 단계 감소 |
| 시간·연락처 없음 | 공식 안내가 있는 10개 시설 보강, 카페 자료 연결 | 방문에 필요한 정보 |

확장 폭에서도 콘텐츠는 가독성 있는 정렬을 유지한다. 큰 글자에서는 배지를 줄바꿈하고 버튼·이름의 높이는 내용에 맞춘다. 층과 시설을 색만으로 전달하지 않는다. 모든 주요 터치 영역은 44pt 이상, 본문은 시스템 글자 스타일, 움직임은 시스템 전환만 사용한다.

자료는 건물 251개·기존 시설 646개를 보존한다. 지도에는 약국 1·편의점 17·카페 28개를 건물별로 묶는다. 정확한 매장 좌표·실내 경로를 만들지 않는다. 약국은 서울대 공식 편의시설 페이지, 9개 편의점은 생협 공식 운영표를 2026-11-27 확인해 보강했다. 시간은 공개 표의 안내이며 실시간 영업 상태가 아니다. 전화번호가 없는 시설에 건물 대표번호를 대신 표시하지 않는다.
