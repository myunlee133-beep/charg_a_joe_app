# iOS 건물 경험 개편 · 2026-11-26

사용자가 제공한 네 장의 레퍼런스가 기존 목록 중심 설계보다 우선한다.

- 대상: 서울대 캠퍼스를 찾는 학생, iOS / SwiftUI / iOS 17 이상.
- 구조: 지도에서 건물을 선택하면 사진이 있는 건물 시트를 바로 연다. 사진·제목·즐겨찾기 → 길찾기 배너 → 홈 / 시설정보 / 식당·카페 / 이용안내 탭.
- 첫 화면에는 기능 카드 네 개(할 일·알림, 공강 공간, 내부 공간 찾기, 시설 현황), 다가오는 할 일, 내 시간표 진입을 배치한다. 긴 소개·출처는 안내 탭으로 이동한다.
- 색: 흰색과 차분한 회색 바탕, 기존 브랜드와 가까운 초록 #00866B, 민트 #E5F5EF. 시스템 한국어 글꼴. 건물 제목 26pt, 카드 제목 headline, 보조정보 subheadline/caption.
- 서명 요소: 실제 사진 아래의 민트 길찾기 배너와 초록 탭 밑줄.
- 레퍼런스의 카드 구성과 정보 밀도를 따르되 iOS 시트·뒤로가기·폼·글자 크기를 사용한다. 작은 화면과 접근성 글자에서는 가로줄을 억지로 압축하지 않는다.
- 연구실은 교수·연구분야 우선, 설명 접기. 카페는 실제 공식 메뉴 사진. 식당의 기존 식단 화면은 유지한다.
- 시간표·할 일·즐겨찾기는 기기 로컬에 저장하고 사용자가 직접 관리한다. 방문 알림은 사용자가 요청한 항목만 기기 알림으로 예약한다.
- 일정 추천은 실제 입력 일정의 빈 구간과 공개 운영시간으로 계산한다. 혼잡도·좌석 수·콘센트·보행시간·실내 경로는 출처 없는 값을 생성하지 않는다. 실시간 연결 정보가 없으면 확인 불가로 명시한다.
- 사진은 공식 지도와 운영기관의 실제 이미지, URL·확인일·해시를 보존한다. 사용자 레퍼런스 이미지는 저장소에 업로드하지 않는다.
- main의 AR, 지도 선택, 필터 유지와 앱 내 길찾기를 보존한다.
- 검증: 로직 테스트(겹치는 일정/자정/잘못된 시간/빈 일정/알림 범위), iOS 빌드, 실제 시뮬레이터 화면과 주요 터치 흐름, 큰 글자 확인.
