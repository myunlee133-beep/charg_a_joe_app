# 개인정보 처리방침 및 수집·이용 안내

문서 버전: 2026-11-03.2

시행일: 2026년 11월 3일
운영자·개인정보 보호책임자: 이경록
권리 행사·문의: info@chargajoe.org

1. 처리 항목과 목적
계정: 이메일(이메일 가입 또는 Google에서 제공하는 경우), 인증 제공자 식별 정보, 계정 UUID, 닉네임, 만 19세 이상 확인 여부, 약관별 문서 버전·동의 시각을 가입, 본인 계정 구분, 인증, 의사소통 및 동의 이력 관리에 사용합니다. 비밀번호 인증은 Supabase Auth가 처리하며 비밀번호 원문을 앱의 프로필·퀘스트 테이블에 저장하지 않습니다. 생년월일·주민등록번호·학생증을 수집하지 않습니다.
퀘스트: 의뢰·수행 계정 연결, 제목·내용·선택한 캠퍼스 장소·보상액·수락·제출·승인·취소 및 이의 기록을 의뢰 이행과 분쟁 처리에 사용합니다. 공개 목록에는 닉네임과 의뢰 내용을 표시하며 이메일, 내부 사용자 ID, 제출 결과 및 은행 계좌 정보를 반환하지 않습니다. 제출 결과는 해당 작성자와 의뢰자, 업무상 필요한 운영자에게만 제공합니다.
직접 송금: 거래 번호, 의뢰·수행 연결, 보상액, 송금 신고·입금 확인 시각과 상태를 보상 의무와 거래 이력 확인에 사용합니다. 은행 조회나 실제 이체 결과를 자동 수집하지 않습니다. 수행자가 별도 제공에 동의할 때만 은행명·예금주·계좌번호를 해당 거래의 송금자에게 안내합니다. 카드번호, 계좌 비밀번호, 인증번호 또는 은행 로그인 정보를 받지 않습니다.
커뮤니티·분실물: 글·댓글·신고·차단·소유 확인 내용과 계정 연결을 해당 기능과 악용 대응에 사용합니다. 익명 표시는 다른 이용자에 대한 표시 방식이며 서버에서 계정 연결을 제거하는 기능이 아닙니다.
위치: 이용자가 허용하면 기기에서 현재 위치·방향을 지도와 거리 표시용으로 처리합니다. 이 변경에서 위치 이동 이력이나 현재 GPS 좌표를 계정 DB에 저장하지 않습니다. 이용자가 퀘스트·분실물에 선택해 등록한 장소는 게시 내용으로 처리됩니다. 서버·지도·메일 서비스에는 통신 과정에서 IP 주소, 요청 시각, 오류·보안 로그가 생성될 수 있습니다. 광고 추적·마케팅 수신 동의는 이 동의에 포함하지 않습니다.

2. 처리 근거와 선택
회원 운영과 퀘스트 이행에 필요한 항목을 명시한 목적에 한해 처리합니다. 회원가입 시 위 계정 정보의 수집·이용 동의를 받으며, 동의하지 않으면 회원 기능을 이용할 수 없습니다. 앱의 캠퍼스 기능은 로그인 후 이용할 수 있습니다. 은행 계좌 안내는 별도 선택·동의를 받고, 거부하면 앱 내 계좌 안내만 이용할 수 없습니다. 당사자가 별도로 합의한 지급 방법을 사용할 수 있습니다. 필수 처리와 무관한 마케팅 이용은 하지 않습니다.

3. 공개·제공과 수탁 처리
다른 이용자는 공개된 닉네임과 게시 내용을 볼 수 있습니다. 거래 상대방에게 계좌를 안내하는 경우 별도 화면에서 제공받는 상대방, 항목, 목적, 보유 기간을 알리고 동의를 받습니다. 업무상 필요한 운영자만 비공개 거래·신고 정보를 확인할 수 있습니다. 법령 근거가 있거나 별도 동의를 받은 경우 외에는 회원 정보를 판매하거나 제3자에게 제공하지 않습니다.
Supabase Pte. Ltd.는 인증, PostgreSQL 데이터 저장 및 관련 서버 운영을 처리하는 수탁 서비스입니다. 해당 프로젝트의 기본 데이터·인증 저장 지역은 인도 뭄바이(ap-south-1)입니다. 기반 클라우드 등 재수탁 처리는 Supabase의 공개 수탁자 목록과 계약에 따릅니다. Kakao 지도 서비스는 지도 요청과 기기에서 허용한 위치 관련 정보를 해당 기능에 필요한 범위에서 처리합니다. 소셜 로그인은 선택한 Google 또는 카카오 계정의 인증 결과를 Supabase Auth에 연결합니다. Google은 계정 식별자와 이메일, 카카오는 계정 식별자와 선택 동의한 닉네임을 제공합니다. 카카오 이메일·프로필 사진·친구목록·전화번호는 요청하지 않으며 이메일이 없는 소셜 회원도 같은 계정 UUID로 구분합니다. 제공자별 인증·동의 화면과 해당 제공자의 개인정보 처리방침이 적용됩니다. 이메일 인증·비밀번호 재설정 발송은 Brevo SAS(프랑스, 문의 dpo@brevo.com)에 위탁하며 수신·발신 이메일 주소, 인증 안내 내용, 발송 시각·전달 결과 등 필요한 통신 정보를 처리합니다. 퀘스트 본문·보상·계좌 정보를 메일 업체에 전달하지 않습니다. Brevo의 주 저장·백업 국가는 프랑스·독일·벨기에이며 지원·보안 처리 재수탁 정보는 https://www.brevo.com/legal/termsofuse/ 의 DPA에 공개됩니다. 수탁 서비스 또는 이전 조건 변경 시 정책에 반영하고 필요한 고지·동의를 진행합니다.

4. 국외 처리
국외 처리에 관한 별도 안내·동의 문서를 함께 제공합니다. 이메일, 인증 정보, 프로필, 동의 이력, 이용자가 등록한 퀘스트·커뮤니티·분실물 정보, 거래 상태 및 별도로 제공한 계좌 안내가 Supabase 기반 서버에 암호화 통신으로 전송됩니다. 해외 저장을 원하지 않으면 가입을 진행하지 않거나 계정 삭제 지원을 요청할 수 있습니다.

5. 보유·파기
인증 메일의 Brevo 발송 로그는 발송 후 1개월 보관하도록 설정하며 종료 후 공급자 자동 정리에 최대 24시간이 추가될 수 있습니다. 인증 메일 원문의 미리보기는 별도 저장하지 않습니다. 보안상 발송 차단에 필요한 수신 거부·반송 정보와 공급자 백업은 관련 목적과 계약상 파기 주기에 따릅니다.
계정 정보와 프로필은 회원 기간 동안 보관하고 탈퇴 시 삭제합니다. 이행·보상·분쟁이 남아 있으면 필요한 정보의 처리를 제한한 채 의무 정리와 삭제 지원을 진행합니다. 법령상 보존이 필요한 계약·청약철회, 대금 지급·서비스 공급 기록은 거래 종료 후 5년, 소비자 불만·분쟁 처리 기록은 처리 종료 후 3년 보관하며 동일 기록에 여러 근거가 있으면 필요한 기간을 적용합니다. 앱의 거래 상태 기록은 은행의 이체 증빙을 대신하지 않습니다. 보존 기록에서는 탈퇴한 계정의 로그인 연결을 해제하고 별도 내부 거래 식별자만 유지합니다. 가명 식별자 역시 접근 통제 대상 개인정보로 취급합니다.
계좌 안내 원문은 입금 확인 후 30일 이내에 삭제하며 제공자가 철회하거나 탈퇴하면 앞서 삭제합니다. 확정 거래의 제출 결과 원문은 종료 후 30일 이내에 제거합니다. 거래로 이어지지 않은 취소 의뢰는 종료 후 30일 이내에 삭제합니다. 보존이 필요한 최소 거래 내용과 금액·상태·확인 기록은 별도로 유지합니다. 목적·보존 기간이 끝난 전자 기록은 복구가 어렵도록 삭제합니다. 공급자의 백업·로그는 해당 서비스의 계약상 보존·파기 주기에 따라 처리하며 운영 DB에서 삭제된 정보가 다시 서비스에 사용되지 않도록 합니다.

6. 보호 조치와 권리
암호화 통신, 기기 Keychain에 인증 토큰 저장, DB의 기본 직접 접근 차단, 거래 당사자·운영 역할별 접근 제한을 적용합니다. 계좌·이메일·내부 계정키를 공개 API와 앱 로그에 노출하지 않습니다. 이용자는 내 정보에서 닉네임 수정·로그아웃·계정 삭제를 요청할 수 있고, 거래 화면에서 계좌 제공을 철회할 수 있습니다. 열람, 정정, 삭제, 처리 정지, 동의 철회와 대리인 요청은 info@chargajoe.org로 접수하며 본인 확인 후 법정 절차에 따라 처리합니다. 법률상 보존 대상 정보는 해당 사유와 기간을 안내하고 목적 외 이용을 제한합니다.

7. 구제와 변경
개인정보 침해 신고는 개인정보침해신고센터(privacy.kisa.or.kr), 분쟁 조정은 개인정보분쟁조정위원회(kopico.go.kr)를 통해 신청할 수 있습니다. 정책 변경 시 앱에서 주요 변경과 시행일을 알립니다. 권리·의무에 중요한 영향이 있는 변경은 필요한 동의를 다시 받습니다.
