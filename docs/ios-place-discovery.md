# iOS 장소 탐색

지도에서는 건물 요약을 보여주고, 층별 공간·식당과 카페·이용 안내는 선택한 뒤 탐색합니다.

연구실은 지도교수와 주요 연구분야를 먼저 보여줍니다. 설명과 위치, 연락처, 출처는 기본적으로 접어 둡니다.

카페에는 공식 메뉴 사진을 사용합니다. 식당의 기존 날짜·끼니 선택과 메뉴 화면은 유지합니다.

## iOS 화면 구성

- 지도 카드는 건물명·동 번호와 `건물 둘러보기`, 기존 앱 내 `길찾기`만 표시합니다.
- 하나의 기본 시트 안에서 `NavigationStack`으로 이동합니다. 개요에서 층별 공간, 식당·카페, 이용 안내 중 필요한 항목만 엽니다.
- 층 선택은 현재 층만 표시하며 연구실·지도교수·연구분야 검색은 건물 전체를 대상으로 합니다. 상세에서 뒤로 가도 검색어와 선택 층을 보존합니다.
- 연구실 설명·호실·전화·출처는 기본적으로 접힌 `DisclosureGroup` 안에 있습니다. 지도교수와 연구분야 태그가 먼저 보입니다.
- 카페는 시그니처 사진과 메뉴 사진을 먼저 표시합니다. 메뉴를 누르면 메뉴별 사진·설명·가격 공개 여부·공식 출처로 이동합니다.
- `카페109 디저트 모음`은 매장 소개 사진으로만 표시하며 개별 도넛 사진으로 쓰지 않습니다. 사진이 없는 매장에는 다른 매장 사진을 대신 넣지 않습니다.
- 식당 진입은 기존 지도 식당 시트로 연결합니다. 식당 탭의 날짜·끼니·가격·영업·즐겨찾기 필터와 전체 메뉴 카드를 유지하며 상단에 카페 목록 진입만 추가했습니다.
- 시스템 글자 크기, 줄바꿈, 44pt 이상 주요 터치 영역과 VoiceOver 레이블을 사용합니다. 접근성 글자 크기에서는 카페 메뉴를 한 열로 표시합니다.

## 데이터와 출처

건물 기본 ID·번호·좌표를 유지한 오프라인 251개 건물과 공식 등록 시설 646개를 사용합니다. 건물 상세 모델·자료는 기존 PR #16의 구조를 이어받고, 지도 선택·필터 유지·지도 여백 처리는 PR #15의 현재 변경을 포함합니다. main의 PR #14 앱 내 길찾기를 유지합니다.

컴퓨터공학부 공식 연구실 중 건물 번호가 등록된 연구실 32곳, 공식 매장 안내를 확인한 카페·간식 매장 7곳을 별도 번들로 제공합니다. 303동 연구실 4곳은 연결할 공식 지도 건물 ID가 없어 원자료의 `unmappedLabs`에 보존하고 화면에 임의 배치하지 않습니다. 모든 연구실을 수록한 목록이 아니라는 범위를 화면에 표시합니다.

연구실 설명과 연구분야는 [서울대학교 컴퓨터공학부 공식 소개](https://cse.snu.ac.kr/ko/research/labs)를 바탕으로 정리했습니다. 매장 안내는 [서울대학교 생활협동조합](https://snuco.snu.ac.kr/카페안내/), 사진은 [파스쿠찌 공식 메뉴](https://www.pascucci.co.kr/product/productList.asp?typeCode=00100020)와 [서울대학교 카페109 소개](https://new.snu.ac.kr/snunow/snu_story?bbsidx=176312&md=v)를 사용합니다. 각 레코드에 공식 URL과 확인일을 보존합니다. 미공개 가격은 만들어 넣지 않으며 당일 판매·옵션·가격은 매장 확인으로 안내합니다.

메뉴 사진 6장은 원본과 동일하며 `docs/menu-photo-sources.json`의 SHA-256으로 검사합니다. 이미지와 정보는 모두 번들에 포함되어 오프라인에서도 열람할 수 있습니다. 출처·운영기관 링크와 길찾기는 네트워크를 사용합니다.

## 검증

Windows에서는 Xcode를 실행할 수 없어 macOS GitHub Actions에서 `swift test`, XcodeGen 생성, 시뮬레이터 빌드와 XCUITest를 실행합니다. `python3 tools/validate_place_resources.py`는 연결된 건물 번호, 공개 자료의 범위, 사진 출처·해시를 검사합니다. 네이티브 UI 테스트는 지도 탭·검색, 연구실 설명의 기본 접힘과 펼치기, 뒤로 가기 후 검색 보존, 카페 사진·메뉴 상세, 기존 식당 컨트롤, 접근성 글자 크기를 확인하고 스크린샷을 보관합니다.

Debug 전용 실행 인자 `-preview-place-building 301` 또는 `111`로 실제 번들 자료의 해당 건물 탐색 화면을 열 수 있습니다. 화면 변경은 서버나 계정 데이터에 쓰지 않으며 앱 배포와 별개입니다.
