# iOS 건물 허브 · 레퍼런스 개편 (2026-11-26)

사용자가 제공한 네 장의 레퍼런스를 기준으로 기존 목록 중심 화면을 사진·탭·기능 카드 중심의 SwiftUI 화면으로 변경했습니다. 레퍼런스 이미지는 저장소에 업로드하지 않았습니다.

## 화면과 동작

지도·검색에서 건물을 선택하면 사진이 있는 건물 시트가 바로 열립니다. 기본 높이에서는 지도를 함께 보고, 드래그해 전체 화면으로 펼칠 수 있습니다. 시트 높이에 맞춰 선택 건물의 지도 여백을 조정합니다. 건물명·동 번호·분류·즐겨찾기, 실제 사진, 민트색 앱 내 길찾기 배너를 먼저 보여줍니다.

탭은 홈 / 시설정보 / 식당·카페 / 이용안내입니다. 홈의 기능 카드는 할 일·방문 알림, 공강 공간 추천, 내부 공간 찾기, 시설 현황으로 연결됩니다. 다가오는 할 일, 내 시간표, 주요 등록 시설도 확인할 수 있습니다. 시설정보에서는 층을 바꾸거나 연구실·지도교수·시설을 검색합니다. 연구실의 지도교수·연구분야 우선 표시와 설명 펼치기를 유지합니다. 카페는 공식 메뉴 사진을 사용하며 식당의 기존 날짜·끼니·필터·메뉴 화면을 보존합니다.

시간표에는 요일·시간·수업명·건물·호실을 등록·수정·삭제할 수 있습니다. 공강은 겹치는 일정과 중복 운영 구간을 합친 뒤 계산하며 30분 이상을 안내합니다. 모든 시각은 서울 기준입니다. 시간표가 비어 있으면 실제 수업을 등록하도록 안내하고 개인 일정을 예제로 채워 넣지 않습니다.

건물별 할 일은 추가·수정·완료·삭제할 수 있습니다. 종 아이콘을 누를 때만 iOS 알림 권한을 요청하고 해당 방문을 한 번 예약합니다. 수정·완료·삭제 시 기존 알림을 취소합니다. 앱이 열려 있을 때의 알림도 처리하며, 알림을 누르면 관련 건물의 할 일로 이동합니다. 시간표·할 일·즐겨찾기는 이 기기의 UserDefaults에 저장되며 서버에 전송하지 않습니다.

공강 공간은 공식 등록 카페·라운지·도서·학습 공간 중 선택 건물과 가까운 곳을 보여줍니다. 시설의 공식 분류를 사용해 도서관 이름이 들어간 ATM·행정실·주차장·AED 설치 지점을 학습 공간으로 잘못 추천하지 않습니다. 다음 수업 정보가 있으면 남은 시간을 표시하고 건물 간 앱 내 길찾기를 연결합니다. 지도에는 등록 건물 위치만 표시하고 실제 보행 경로·시간은 기존 길찾기에서 확인합니다.

## 데이터가 없는 항목

혼잡도·실시간 좌석 수·콘센트·정숙도·실내 보행 경로를 제공하는 연결 데이터가 없습니다. 따라서 확인되지 않은 혼잡/여유 배지·이용 추이·좌석 수·실내 경로를 만들지 않습니다. 시설 현황에는 이 상태와 공식 등록 운영시간을 표시합니다. 내부 공간 찾기는 확인된 층과 호실을 안내합니다. 일정 추천은 혼잡도 예측이 아니며 시설의 공개 운영시간이 없는 경우 공강만 표시하고 운영 여부를 별도 확인하도록 안내합니다.

## 사진과 자료

기존 건물 251개의 ID·번호·좌표·좌표 출처를 유지했습니다. 등록 시설 646개, 연결 가능한 연구실 32곳, 카페·간식 매장 7곳과 공식 메뉴 사진 6장을 보존합니다. 미등록 303동 연구실은 임의 건물에 연결하지 않습니다.

[서울대학교 공식 캠퍼스 지도](https://map.snu.ac.kr/)의 건물별 자료에서 공식 동 번호가 일치하는 사진 연결 232건을 확인했습니다. 학생회관·공학관·도서관 등 주요 건물 원본 사진 12장은 번들에 포함합니다. 다른 건물 사진은 공식 URL에서 불러오며 연결되지 않거나 오프라인이면 사진 준비 중 상태로 표시합니다. building_photos.json에 건물 ID·공식 출처·확인일과 번들 사진 해시를 보존합니다. 갤러리 장수와 이미지는 임의로 늘리지 않습니다.

[컴퓨터공학부 공식 연구실](https://cse.snu.ac.kr/ko/research/labs), [생활협동조합](https://snuco.snu.ac.kr/카페안내/), [파스쿠찌 공식 메뉴](https://www.pascucci.co.kr/product/productList.asp?typeCode=00100020), [서울대학교 카페109 소개](https://new.snu.ac.kr/snunow/snu_story?bbsidx=176312&md=v)를 기존 출처로 유지합니다. 가격 미공개와 자료의 일부 수록 범위를 화면에서 안내합니다.

## 실행과 검증

main 212bebb의 AR·지도 기능, 정차 차량을 숨기는 셔틀 수정과 앱 내 길찾기를 보존했습니다. Swift 모델 테스트는 swift test, 자료·사진 검사는 python3 tools/validate_place_resources.py로 실행합니다. iOS 프로젝트는 xcodegen generate --spec ios/project.yml로 생성할 수 있으며 체크인된 Xcode 프로젝트에도 새 소스와 자료를 연결했습니다.

Windows에서는 Xcode를 실행할 수 없어 기존 macOS CI에서 모델 검사, iOS Simulator 빌드와 XCUITest를 실행합니다. 네이티브 테스트는 실제 지도 탭·검색 진입, 연구실 접기·펼치기, 카페 메뉴 사진, 기존 식당 컨트롤, 레퍼런스 건물 홈·탭·시설 상태, 시간표·할 일 저장과 재실행 보존, 접근성 큰 글자를 검증하고 캡처를 남깁니다. 알림의 실제 배너 표시·소리·잠금 화면 전달은 권한을 허용한 실제 기기에서 추가 확인이 필요합니다.

Debug 실행 인자 -preview-place-building 63 또는 301로 실제 번들 건물의 새 시트를 전체 높이로 열 수 있습니다.
